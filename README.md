# ورقة 2.0 — استوديو الرسم

نسخة متكاملة من الاستوديو العربي، جاهزة كملفات ثابتة على GitHub Pages. إعدادات مشروع Firebase الخاص بك موجودة في firebase-config.js. ابدأ بدليل [الإطلاق والإدارة والدومين](LAUNCH.md).

## الجديد

- هوية بنفسجية هادئة مع درجات خوخية وخضراء، ورسوم واجهة أصلية دون ملصقات.
- 20 أداة: رصاص، حبر، فرشاة، مائي، ماركر، شمع، فحم، باستيل، خط عربي، فرشاة ناعمة، رذاذ، مضيء، طيف، خط، مستطيل، دائرة، مثلث، تعبئة، ممحاة، قطارة.
- 90 لونًا في خمس مجموعات، مع اختيار لون مخصص والحجم والكثافة والتنعيم وضغط القلم.
- 12 تخطيطًا في مكتبة مصغرات، ونمطان: نص لكل لاعب أو رسم حر مشترك.
- غرف لشخصين بهويتين مجهولتين، رابط مشاركة، حضور، مزامنة وتراجع لحظي.
- تكبير وتصغير، شبكة مساعدة لا تظهر في التصدير، ووضع تركيز.
- تنزيل PNG أو JPG أو WebP، ومعرض محلي، وحفظ وفتح مشروع قابل للتحرير مع طبقات اللاعبين.
- صفحة رسمة الأسبوع، ترشيحات خاصة، لوحة إدارة بدخول بريد وكلمة مرور وصلاحيات Firebase، نشر ذري ورفض وإزالة من المعرض.
- صفحة خصوصية، أيقونة وملف manifest، وصورة مشاركة وأداة لإعداد canonical وsitemap والدومين.

## التشغيل

من هذا المجلد، نفّذ `npm start` ثم افتح http://127.0.0.1:4173. لا تستخدم file:// لأن الموقع يستخدم JavaScript modules. لا يحتاج التشغيل أو GitHub Pages إلى npm install؛ الاعتماديات مطلوبة للاختبارات فقط.

## التحقق

نجحت 6 اختبارات للمحرك و3 مجموعات اختبارات على Firebase Emulator، تشمل الأدوات والتعبئة وعزل الطبقات وحماية الغرف وخصوصية المشاركات وصلاحيات الإدارة والنشر الذري والمزامنة الحية. نجح أيضًا فحص ملفات JavaScript وروابط الأصول والمعرّفات.

لإعادة الاختبارات: `npm install` ثم `npm run check` و`npm run test:engine` و`npm run test:rules`. اختبار القواعد يحتاج Java 21. محاكي الاختبار يستخدم مشروع demo-waraqa ولا يكتب في قاعدة الإنتاج.

لم يتم نشر القواعد الجديدة أو تعيين حسابك أدمن أو نشر الموقع أو ربط دومين فعلي. اختبار الإدارة الكامل بالنقر في المتصفح لم يكتمل بسبب رفض أداة المتصفح الاتصال بمنفذ الاختبار الإضافي. التفاصيل والخطوات المتبقية موثقة في LAUNCH.md.

## ملاحظات الاستخدام

التراجع والممحاة يخصان طبقة اللاعب نفسه. ترتيب طبقات المستخدمين ثابت على الجهازين. تعبئة اللون تسترشد بطبقتك والتخطيط، ولا تعتبر خطوط شريكك حدودًا للتعبئة. المعرض المحلي يبقى في هذا المتصفح، والتنزيل يحفظ نسخة مستقلة. القواعد تحجز المقعدين حتى يعود صاحب الهوية من المتصفح نفسه؛ الخروج لا يحرر المقعد لشخص ثالث.

المشاركات ترسل اختياريًا بعد موافقة صاحب الرسم، ولا تظهر للناس إلا بعد نشر الإدارة. لم تتضمن النسخة أعمال مجتمع أو أرقام تفاعل تجريبية في البيانات الحية.
